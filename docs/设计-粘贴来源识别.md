# 设计稿：粘贴自动识别数据来源位置（📍来源标签）

> 状态：设计稿（未实现）。场景：用户在 Excel 复制 A5:S16 → 粘贴到聊天框 → AI 自动知道数据来自 `Sheet1!A5:S16`。
> 复用现有约定：`[工作表!地址]` 方括号片段（与「插入选区」按钮一致）、toast/错误条、运行日志。

---

## 一、交互稿（ASCII 线框）

### 场景 1：正常识别（单命中）——主流程

```text
┌─────────────────────────────────────────────────────────┐
│ 聊天页                                                   │
│  …消息流…                                                │
│                                                          │
│ ┌ 📍 来源识别 ────────────────────────────── ✕ ┐  ← 识别成功后出现在输入框上方
│ │ Sheet1!A5:S16 · 12 行 × 19 列 · 表头：员工编号、 │     │
│ │ 姓名、性别…（原生剪贴板格式，精确命中）           │     │
│ │           [📍 插入位置引用]   [忽略]            │     │
│ └────────────────────────────────────────────────┘     │
│ ┌──────────────────────────────────────────────┐        │
│ │ 输入框：                                     │        │
│ │ 员工编号  姓名  性别  出生日期 …（用户粘贴的内容，│        │
│ │ 原样保留）                                    │        │
│ └──────────────────────────────────────────────┘        │
│ [＋插入选区] [发送]                                       │
└─────────────────────────────────────────────────────────┘
```

- 用户点 **[📍 插入位置引用]** → 输入框最前面自动追加 `[Sheet1!A5:S16] `（与「插入选区」同一方括号约定），chip 消失。
- 用户点 **✕ / 忽略** → 只丢弃 chip，粘贴的内容不动。
- **用户直接点发送**：若 chip 还在，发送前自动把 `[地址] ` 前置进消息（无感带上位置），chip 消失。

### 场景 2：内容匹配到多个候选（多命中）

```text
┌ 📍 来源识别 · 检测到多个可能来源 ────────────── ✕ ┐
│ 请选择数据的实际来源：                             │
│  ○ Sheet1!A5:S16   12 行 × 19 列（相似度 98%）    │
│  ○ 汇总!B3:D14     12 行 × 3 列 （相似度 71%）    │
│            [📍 插入选中引用]   [忽略]             │
└──────────────────────────────────────────────────┘
```

- 单选按钮 + 确认；相似度只用于排序展示。

### 场景 3：识别失败（兜底）

```text
showToast("未能在工作簿中定位粘贴的数据，可用「＋插入选区」手动指定。")
（不弹 chip，不打断粘贴）
```

### 场景 4：普通文本粘贴（不触发）

- 粘贴内容 < 2 行或 < 2 列、或不含制表符/表格特征 → 完全静默，走系统默认粘贴。

### 开关

- 输入框上方 chip 首次出现时附一次提示；设置页「运行日志」旁新增
  `☑ 粘贴自动识别来源`（localStorage 持久化，默认开）。

## 二、实现逻辑

### 2.1 后端（SidebarBridge 新增 1 个 public 方法）

```csharp
public Task<string> ResolveClipboardRange()
```

三层识别，从准到兜底，全部本地执行（剪贴板数据不出机器）：

**L1 · Excel 原生剪贴板格式（精确）**
- `System.Windows.Forms.Clipboard.GetDataObject()`，依次尝试 `GetData("XML Spreadsheet")`、`GetData("HTML Format")`。
- XML Spreadsheet 2003 里带 `ss:Worksheet ss:Name` 与单元格 `ss:Index` → 解析出 **工作表名 + 区域范围 + 表头行**（可加 `DataObject` 中存在的源选区信息则直接用）。
- 上限保护：剪贴板字符串 > 4MB 时跳过 L1（防超大复制约卡 UI 线程）。

**L2 · 内容指纹匹配（兜底，读活动工作簿）**
- 把剪贴板纯文本按 TSV 解析为矩阵（行数 R、列数 C）。
- 对活动工作簿每张表的 `UsedRange` 读值（上限 2 万格，超出采样：首行、首列、末行、末列 + 左上/右下角值）。
- 指纹比对打分：`维度相同(+40) / 表头行逐格相等(+30) / 左上角值相等(+15) / 右下角值相等(+15)`，≥70 记候选，按分排序。
- 0 候选 → notFound；多个 → 候选列表。

**返回 JSON（两层面统一）**
```json
{ "ok": true, "source": "native|fingerprint",
  "candidates": [ { "sheet": "Sheet1", "address": "A5:S16",
                    "rows": 12, "cols": 19,
                    "headers": ["员工编号","姓名","性别"] } ] }
```
- 全程 try/catch，任何异常降级为 notFound（识别是增强功能，绝不阻断粘贴）。
- `DiagnosticsLog.Info("粘贴识别：Sheet1!A5:S16（native）")` 留痕。

### 2.2 前端（index.html）

**粘贴监听**（仅聊天输入框 `elements.prompt`）：
```js
prompt.addEventListener("paste", () => {
  if(!pasteAutoLocateEnabled()) return;               // 设置开关
  setTimeout(resolveAndShowChip, 60);                 // 等系统剪贴板就绪后再识别
});
async function resolveAndShowChip(){
  const text = 剪贴板纯文本;
  if(!looksLikeTable(text)) return;                   // <2 行或 <2 列 → 静默
  const r = parseResult(await asyncBridge.ResolveClipboardRange());
  renderSourceChip(r);                                // 单命中/多候选/失败 三态
}
```
- **不 preventDefault**：粘贴行为保持系统默认，chip 只是附加提示。
- `looksLikeTable`：行数≥2 且 首行列数≥2 且（含 \t 或行宽一致）。

**chip 状态机**：`pendingRef = { sheet, address, rows, cols }`
- [插入位置引用] → `prompt.value = "[" + sheet + "!" + address + "] " + prompt.value`，清 chip；
- 发送时 chip 未处理 → 发送前自动前置同上；
- ✕/忽略 → 清 chip。

**开关**：设置页运行日志卡片加 `☑ 粘贴自动识别来源`（localStorage `xai-paste-locate`，默认开）。

### 2.3 关键边界

| 边界 | 处理 |
|---|---|
| 剪贴板被覆盖/非 Excel 复制 | L1 拿不到原生格式 → L2 指纹；都失败 → 场景3 兜底提示 |
| 多工作簿 | L1 原生格式带簿名（可显示）；L2 只扫活动簿（后续可扩展 externalBooks） |
| 大区域 | L1 4MB 上限；L2 2 万格上限 + 采样 |
| 隐私 | 全部本地匹配，无网络 |
| 性能 | paste 后 60ms 延迟识别，单次本地操作 <100ms 量级 |
| 非 Excel 复制的表格（网页/Word） | L1 无 → L2 内容匹配若命中工作簿同形数据同样可用；否则兜底提示 |
