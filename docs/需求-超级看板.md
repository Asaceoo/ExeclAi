# 需求-超级看板（Super Dashboard / 超级看板）

> 版本：v1.0（2026-09-12，grill-me 八问收敛拍板，决策记录见 §3；竞品依据=BV17c411P7BN 之了学吧销售仪表盘 55.1 万播放视频拆解 + 杰瑞 BV1Agt36VEKV）
> 状态：已拍板待实现（P1 待启动）
> 上游：`docs/需求-原生数据看板.md`（看板渲染主链）、`create_super_table`（超级数据表 v3.7.1.33）、`docs/需求-看板编辑器.md`、竞品调研 BV17c411P7BN（透视表+计算字段+报表连接+文本框绑定+四宫格看板）

## 1. 背景与动机

竞品视频 BV17c411P7BN（55.1 万播放）验证了看板赛道的核心需求：小白用户要的不是"会画图表"，而是**一键得到"整体联动+好看"的成品看板**。视频教用户 17 分钟手工搭出"数据表→透视表→看板"三层结构（5 KPI 卡+5 切片器+4 张透视图），我们的目标是用 AI 把这 17 分钟变成一句话/一次点击。

项目已有约 80% 骨架：`create_super_table` 数据底座、`render_dashboard` 渲染主链（KPI 卡+图表+多字段切片器联动，真机验证）、`verify_dashboard_deep` 深度核验+截图闭环。本需求补齐剩余差距：**指标可配置可切换、视觉升级、Ribbon 双入口**。

## 2. 一句话定义

**超级看板 = 任意明细数据一键生成"数据表底座 + 汇总透视层 + 固定四宫格看板"三层结构的工作簿成品；切片器多维度多选联动、KPI 指标生成前可配置、生成后可切换、全程自检守恒。**

## 4. 功能定义

### 4.1 三层工作簿结构

```
┌─ 数据表层 ── 超级数据表（create_super_table：明细长表 + 汇总区；已有则复用）
├─ 汇总透视层 ─ _超级看板_calc（staging：全指标 SUMIFS+切片器掩码，隐藏，AI 可核验）
│              └ [可选开关] "透视分析" sheet（用户可见可拖改的 Excel 原生透视表，仅分析用，不进看板主链）
└─ 看板层 ──── 超级看板 sheet：标题栏 + KPI 卡区（含指标选择器）+ 固定四宫格 + 左右切片器列
```

### 4.2 双入口

- **侧边栏自然语言**（P1）："帮我做一个超级看板，要看利润占比和百万口径"→ AI 走 detect→suggest（确认映射与指标集）→ render → verify → 截图五步闭环。
- **Ribbon 表单**（P2）：功能区"超级看板"按钮 → 参数面板（数据区/维度勾选/指标勾选/单多选模式）→ 一键生成，确定性模板+传参，不经过 AI 对话。

### 4.3 指标选择器（核心增量，Q3-B）

- staging 一次性计算**全部指标**（内置 KPI + 用户配置的 extra_kpis 派生指标，派生公式=字段四则运算+IFERROR 包裹，走守恒对账）；
- 看板 KPI 区放"指标视图"单元格下拉（数据验证），KPI 卡与图表经 INDEX/OFFSET 按所选指标动态取数；
- 切换指标=改一个单元格→公式重算→全板联动，与切片器掩码同族、可深度核验。

### 4.4 版式（Q6）

固定骨架：顶部标题栏；KPI 卡区一行 5 张（圆角矩形+悬浮阴影+数值绑定 staging 引用，含指标选择器）；四宫格图表区（月度趋势组合图/维度排行柱线/占比圆环/第二维度组合图，按数据维度自适应匹配，缺失维度显示引导文案）；左右两列切片器（按维度数量自适应）。

## 7. 非目标与红线

- **不切 PivotChart/透视表引擎主链**（Q1 拍板）：透视表黑盒不可核验、WPS 兼容差；透视分析 sheet 仅作可选附赠，不进看板数据链。
- **本期不做 WPS 超级看板**（Q7）。
- 沿用看板族全部红线：SheetProtectionGuard 前置、StructuralChange 确认门、无半成品语义（失败清理）、生成后自动核验+截图、staging 命名统一 "_"+name+"_calc" 构造。
