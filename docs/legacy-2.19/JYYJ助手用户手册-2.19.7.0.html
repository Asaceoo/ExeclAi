一、产品简介

JYYJ助手 是一个内嵌在 Excel 中的 AI 办公助手。它通过一个侧边栏面板与你的工作表对话，能理解自然语言需求，并自动调用 Excel 工具完成数据读取、清洗、分析、填表、公式生成、图表绘制、报告撰写等一系列操作。

自然语言操作表格用中文描述需求，助手自动执行
公式自动生成选好选区，描述计算，生成即用公式
VBA 宏编写与执行自动生成代码、校验、执行并沉淀复用
多步骤流程编排把常用操作存成可复用流程模板
数据填充与清洗智能填补空格、去重、分列合并
图表与透视按需求自动生成图表、透视表
分析与报告生成结构化数据分析报告
多工作簿协同跨工作簿只读引用多个数据源
适用范围
需配合已安装完成的 JYYJ助手 加载项使用（安装方式见《安装器 用户操作说明》），并配置一个 OpenAI 兼容的模型服务。

二、快速上手

第一步：打开助手

  1. 打开 Excel，在功能区顶部找到 「JYYJ助手」 选项卡。
  2. 点击其中的「侧边栏」按钮，Excel 右侧出现助手面板。
  3. 确认面板顶部连接状态显示「就绪」。

第二步：配置模型（首次）

  1. 切到「设置」视图，找到「模型方案（OpenAI 兼容）」。
  2. 填写接口地址 Base URL、API Key、模型名称，保存。

第三步：开始对话

示例指令
把 A1:A20 求和写入 C1
把第 3 列的空格按邻近值填上
统计各部门人数并做成柱状图

助手会先读取选区，必要时弹确认面板让你审核改动，再执行并汇报结果。

三、聊天对话视图

「聊天」是默认视图，是使用助手最核心的入口。输入自然语言需求即可让助手读取、分析并修改工作表。

3.1 思考过程面板

每条回复下方可展开「思考过程」，按 思考 → 工具调用 → 结果 分步呈现，让你看清助手每一步做了什么、调用了哪个工具、是否需要你对危险操作做确认。

3.2 工具调用上限

重要提示
单轮对话内助手能够自动调用的工具次数有限，可在「设置 → 单轮工具调用上限」中调整（范围 1–1000）。复杂任务可调大，但过大会拖慢单轮响应。

3.3 危险操作确认

对删除行、覆盖关键数据、整行删除、执行宏等危险操作，助手不会直接执行，而是弹出确认面板展示将发生的改动，需你审阅后点击确认才会落地。

3.4 多工作簿协同

当前活动工作簿是写入目标；外部工作簿可经 read_external_range 以只读句柄引用，不修改原文件。可在「设置 → 已连接工作簿」中刷新清单并选择上下文锚点。

4.1 网页停靠

在设置中可启动与助手同款的停靠式浏览器窗格，在 Excel 右侧承载站点页面（可登录、提问、缩放）。同一时刻只承载一个站点，部分拒绝 iframe 的站点（如 DeepSeek）会由独立窗格承载。

五、公式助手

帮助你快速得到正确、可复用的 Excel 公式。

  1. 在工作表上框选「数据选区」（进行计算的区域）。
  2. 框选（或指定）「目标选区」（公式输出位置）。
  3. 用自然语言描述期望的计算。
  4. 点击生成，助手返回一条可直接复制粘贴的公式，并附通俗易懂的文字说明。
说明
公式生成过程不会改动工作表，属于只读操作，可放心使用。

在聊天中直接描述计算需求，同样会让助手生成并写入公式（此时遵循「写入输出偏好」设置）。

六、VBA 代码助手

无需手动编写宏，即可完成 VBA 的编写、校验、执行与沉淀。

6.1 编写 / 粘贴代码

在 VBA 面板中直接编写，或从别处粘贴 VBA 宏代码。

6.2 校验（安全，只读）

点击「校验」，仅做语法结构检查并返回结果，不执行、不改动工作表。

6.3 执行（高危，需确认）

点击「执行」会进入危险确认流程：

  1. 弹出代码预览面板，逐行展示待执行代码；
  2. 你审阅后点击「执行代码」才真正运行。
    提示
    执行前会经过静态护栏检查，拦截如「对多行多列矩形区域直接 AutoFit」等致命写法，避免运行时错误中断宏。

    6.4 自动沉淀与复用

    执行成功的 VBA 代码会自动沉淀到代码库，可在「VBA → 模板库」中查看与复用；未自动沉淀时可点「载入VBA面板」手动处理。沉淀模板命名简洁、凝练、突出功能重点，方便再次调用。

    也可以不写代码，直接在聊天里描述需求，让助手生成并执行宏。

七、流程编排

把常做的一系列操作固化成可复用的流程模板，一键重复执行。

  • 触发已有流程：在聊天框输入 @workflow:流程名称 直接运行。
  • 另存会话为流程：在聊天后，把当前会话中一步成功的工具操作另存为流程模板。
  • 执行特性：逐条调用工具流程，支持危险操作确认与单步失败重试。

8.1 运行日志与一键自检

实时监控助手本轮的行为（写入数据 / 生成的 VBA 代码 / 创建的图表），登录与否都会登记。下方「一键自检」会用 AI 研判最近会话，帮助核实 AI 生成的数据、代码与图表是否正确。

v2.19.4.0：运行日志已覆盖全部功能
不仅登记写操作结果，还记录每个工具调用的执行耗时与成功 / 失败 / 异常路径（含格式化单元格、排序、透视、Python 脚本等全部工具）；Python 脚本的错误输出（stderr / traceback）也会被捕获进日志并在页内折叠展示，不再撑爆单行。某个功能出错时，按「级别 → 工具 → 耗时」过滤即可快速定位是哪个功能、哪一步失败。

8.2 全功能巡检

点击「全功能巡检」按钮，助手会在一个临时工作簿（不影响你当前的数据）里，对全部核心子系统逐项体检并出报告：

  • 写入、公式、排序、清洗、追加行、批量回写、透视（含明细/汇总数量守恒对账）、格式、条件格式、标记、图表、工作表结构——每项都会执行主工具 + 自动自检回读核对；
  • 操作历史与回滚链路端到端验证（写入 → 覆写 → 回滚 → 核对恢复）；
  • 自检覆盖审计、踩坑失败模式库、自检历史趋势库、配置存储与本地技能包加载状态。

巡检逐项结果同时写入运行日志，✔ 表示通过、✗ 表示失败及原因。建议在安装完成或版本升级后运行一次。

8.3 自动自检与「本轮自检」提示

AI 执行写入、排序、清洗、透视、画图等操作后，系统会自动回读核对结果是否与你的要求一致（不依赖 AI 自觉）。检查不通过时 AI 必须先修正才能向你报告完成。每轮对话结束会弹出「本轮自检」摘要（检查了几项、是否全部通过）；一键自检结果页还会显示最近 20 次的通过率与高频问题趋势。

8.4 回滚 AI 的修改

每条 AI 回复下方提供逐个操作回滚按钮，可把某一步写入恢复到操作前的状态；若目标区域在回滚前又被改动过，系统会提示冲突并拒绝，避免覆盖你后来的手工修改。

九、AI 技能包

技能包是存放于本机的、可被 AI 调用的一组指令与能力。存放路径：

%APPDATA%\ExcelAiAssistant\skills\<技能名>\SKILL.md
  • 调用：在聊天中输入 /技能名 即可强制加载并调用该技能。
  • 来源可信性：第三方技能由 AI / 脚本驱动，请确认来源可信后再启用。

十、安全机制

助手内置多层安全设计，保护你的数据不被误改：

  1. 危险操作确认：删除行、覆盖数据、整行删除、执行宏等均需你在确认面板中审阅。
  2. 静态护栏：VBA 执行前拦截易致运行时错误（1004）的写法。
  3. 受控执行：脚本 / CLI / EXE 默认关闭，需显式加入白名单才能启用；命中黑名单直接拒绝。
  4. 只读外部引用：非当前活动工作簿默认只读引用，不修改原文件。
  5. 选区规范：非矩形选区会提示「请选择矩形区域」。
  6. 记忆与自检：通过长期记忆贯彻偏好，通过运行日志与一键自检兜底数据正确性。

十一、常见问题

1. 助手不执行或报错？

先到「设置 → 运行日志 · 自检」查看最近行为记录并执行一键自检；确认模型配置可用、连接状态为「就绪」。

2. 提示“请选择矩形区域”？

助手要求选区为单块矩形。请框选连续的矩形区域后再执行。

3. 助手要执行危险操作怎么办？

这些都会先弹确认面板，你审阅改动即可选择执行或取消。切勿在未审阅情况下直接点确认。

4. 空单元格太多被忽略？

处理空格时若超过 5000 个，会提示「仅处理前 5000 空格，其余忽略」。如需全量处理请分批。

5. 我不想助手直接改表，只想要公式？

在「设置 → 写入输出偏好」中选择「公式优先」，或在公式助手中生成后自行复制粘贴。

6. 生成的 VBA 代码去哪了？

成功执行的宏会自动沉淀到「VBA → 模板库」，可随时复用或载入 VBA 面板修改。
