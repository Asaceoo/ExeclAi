# 自检与工具完备度外部对标调研报告

> 日期：2026-09-08 · 版本基线：v3.1.0.0（134 注册工具 / 13 verify 自检家族）
> 调研范围：GitHub Excel MCP 服务器、Python openpyxl/xlsxwriter、Aspose.Cells、Kutools/Ablebits、Power Query 数据剖析

## 三、本项目已有且不输对标的（不妄自菲薄）

- **自检家族 13 项**（write_result/formula/chart/pivot/sort_filter/structure/data_clean/sparkline/data_validation/merge/cell_format/conditional_format/marker）+ 22 类自动映射 + 豁免审计锁——**没有一家外部 MCP 服务器有任何自检概念**，这是本项目最深的护城河；
- 中文场景专属（金额大写、拼音、简繁转换、工资条、千位序号）——Kutools 部分覆盖，开源界几乎空白；
- 受控执行白名单 / DPAPI / 回滚链路 / 工作流引擎 / 技能包记忆——MCP 服务器均无；
- 双宿主（Excel+WPS）真机 134 工具口径验证——文件型 MCP 用 openpyxl 根本碰不到活工作簿。

## 四、Grilling 追问清单（按 ROI 排序的行动建议）

1. **ROI 最高**：create_excel_table + verify_table（智能表是结构化引用/透视/筛选取数基石，MCP/openpyxl/Aspose 三方都有）；
2. **次高**：verify_protection（当前「写入失败但不知因保护」是真实用户痛点，成本极低——只读探测）；
3. **中**：insert_image（汇报场景高频，Aspose/openpyxl 均支持）+ freeze_panes（一行 COM 调用）；
4. **中**：列质量画像画像工具（对标 Power Query，把 analyze_value_distribution 升级为单面板三联：质量+分布+剖析）；
5. **缓**：sheet copy/move/tab 颜色、图表类型扩展、HTML/JSON 导出——按用户反馈排期；
6. **不推荐追**：OLE/SmartArt/主题（Aspose 是 20 年积累，追平无意义且 WPS 支持差）。

## 五、结论

- **自检体系**：13 verify + 自动映射在外部同类中**独一档**（外部 0 家有自检），但 5 个对象面（表/图/保护/链接/筛选）有 verify 盲区，其中 verify_protection 与 verify_table 优先补；
- **工具面**：134 个在数据清洗/文本/合并拆分/导入导出方向已覆盖 Kutools/Ablebits 核心场景；**结构面（智能表/图片/冻结/分组/工作表管理）是对标后确证的短板**，共 9 项缺口有代码级证据；
- 上述缺口全部可在现架构（服务+Schema+Registration+AutoVerifyPolicy 四件套）内增量补齐，无需动核心。
