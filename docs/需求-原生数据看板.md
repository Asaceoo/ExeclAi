## 1. 背景与机会

竞品（杰瑞工具箱/VBE 直连助手）已验证"AI 生成 Excel 原生看板"的用户价值：其 67 套传参图表模板 + 图表选型手册 + 源数据分表联动的做法，证明了**确定性模板 + AI 出参数**是可规模化的路线。本项目已有 144 工具的写能力底座，补齐看板编排层即可形成同维度竞争力，且无 VBA 依赖（竞品为 VBA 技术栈，本项目 COM 晚绑定，安全分级体系可全程兜底）。

## 2. 目标用户与核心场景

| 用户 | 场景 | 价值 |
|---|---|---|
| 销售/运营（制造业、互联网） | 手里有规整销售流水，汇报前要一张能筛选联动的看板 | 一句话出图，不再逐格手拼 |
| 部门主管 | 周会要看 KPI + 趋势 + 构成，数据每周更新 | 改源数据看板自动重算，模板复用 |

### 3.1 数据门槛（v0.2 新增，D-① 决策：拒绝生成 + 一键转清洗）

生成前数据形态探测是硬闸门，不合规**拒绝生成**（不静默降级、不带病生成），并引导接入现有数据清洗工具：

| 拦截项 | 判定 | 用户出口 |
|---|---|---|
| **疑似合计行/小计行混入明细**（硬拦截） | 行特征：文本标签+数值为同维度部分和 | 提示后一键跳转数据清洗流程，清洗后重测 |
| 合并单元格/多级表头 | 结构探测 | 同上 |
| 文本型数字/多格式日期 | 类型探测 | 同上 |
| 数值列全空/主键列全空 | 基础探测 | 拒绝并说明 |

拒绝理由用可读文案（对应交互稿 S1 探测环节与 AC-9 模式），不暴露技术细节。

## 4. 功能需求（FR）

### FR-1 看板生成（核心，P2 验收）

- FR-1.1 用户以自然语言描述（指定/自动识别数据源），AI 产出看板规格并调用渲染引擎生成完整看板工作表；**生成前必须通过 §3.1 数据门槛（硬拦截项拒绝并引导清洗）**；
- FR-1.2 看板包含：KPI 卡片区、联动筛选区、至少 2 个图表区、统一的主题配色；
- FR-1.3 生成过程一次调用完成，失败时给出可读错误，不残留半成品（失败自动清理）；
- FR-1.4 支持重新生成（幂等覆盖旧看板）与一键删除看板。**删除看板 = 确认门 + 删除前回读断言目标 sheet 确实为看板结构（含特征标记，防误删普通工作表）**（v0.2 D-⑤）；
- FR-1.5 **多看板共存（v0.2 D-⑥）**：允许同一工作簿存在多个看板；sheet 命名自动去重（模板名+序号递增）；spec 与看板 sheet 一一对应，重生成仅覆盖其绑定的看板；
- FR-1.6 **修改语义（v0.2 D-③，v1 边界明示）**：修改 = 调整参数后全量重生成（幂等），**v1 不提供增量修改（patch 指定元素）**；该边界在工具描述与交互稿明示，P3 视用户反馈再议。

### FR-2 数据联动（P2 用单元格方案验收，P3 视探测加原生切片器）

- FR-2.1 筛选维度（如地区、品类）切换后，KPI 数值与图表数据全部自动重算，无需重新生成；
- FR-2.2 联动基于 SUMIFS 辅助区（隐藏 sheet），源数据表只读不修改；
- FR-2.3 联动控件在 Excel 2013 起全版本可用（单元格下拉兜底方案）。

### FR-3 KPI 卡片（P1 验收）

- FR-3.1 支持 4-8 张卡片，字段可配置（求和/计数/均值/比率四类聚合）；
- FR-3.2 数字格式（¥、千分位、百分比）与大字号样式；
- FR-3.3 **KPI 卡三件套（v0.2 回写，对齐设计文档 §5.4）**：数值主体 + 环比箭头（▲/▼ + 条件格式红绿）+ 可选迷你趋势（Sparkline）；**比率类 KPI 一律 IFERROR 包裹，由渲染引擎强制注入，不依赖 AI 记得**；
- FR-3.4 staging 汇总公式**限定实际数据区间（渲染时探测 max row），禁止整列引用**（性能反模式防护，v0.2）。

### FR-4 高级图表（分批验收）

- FR-4.1 P1：双轴组合图、环形图、堆积百分比、雷达图、散点族、迷你图；
- FR-4.2 P2 技巧型：特大值截断柱、子弹图、华夫图、滑珠图、漏斗图、蝴蝶图、甘特图；
- FR-4.3 P3 版本敏感：瀑布图（2016+ 原生/2013 模拟）、直方图/排列图（2016+）、树状图/旭日图（2021+），低版本用户界面明确提示版本徽章；
- FR-4.4 每种图表类型在能力目录中标注兼容版本，不可用时给出替代建议（对标竞品"图表选型 SKILL"思路）。

### FR-5 模板目录（P1 起逐步交付）

- FR-5.1 首批 6 类预设模板：KPI 速览、销售分析（对标视频同款）、财务损益、目标达成、多维交叉、排名动态；
- FR-5.2 AI 按数据形态自动推荐模板（时序→趋势、构成→环形、目标→子弹图等），用户可指定；
- FR-5.3 模板布局参数（位置/尺寸/主题）有默认值，AI 可覆盖。

## 5. 非功能需求（NFR）

| 编号 | 需求 | 指标 |
|---|---|---|
| NFR-1 | 兼容性 | **（v0.2 D-② 收缩承诺，诚实版）**：本机版本真机 harness 验证；其余 Excel 版本做静态兼容性论证（COM API 版本文献核对，版本敏感图表走徽章机制）；**明确声明"未在全部版本实测"，线上兼容性问题以用户反馈兜底、fast-follow 修复** |
| NFR-2 | 性能 | **（v0.6 实测回填，多轮对照实验）**：**2000 行明细：生成 1.4~6.5s、筛选重算 249~586ms（双达标）**；**2 万行明细：生成 9.3~11.4s（受宿主负载波动，处于达标线边缘；优化迭代：基线 14.7s → 行数阈值守卫（≥5000 行启用手动重算）+ sheet 级 Calculate → 9.3s 最佳 / 11.4s 高载），筛选重算 277~529ms（≤1s 达标）**；经验：批量手动重算守卫在小表（公式少）因 COM 模式切换开销反而更慢，须按行数阈值触发；后续优化候选=渲染期间禁用图表重绘；staging 公式禁整列引用（FR-3.4）为前置条件 |
| NFR-3 | 安全 | 全部走现有安全分级：渲染为 StructuralChange 过确认门；**删除看板 = 确认门 + 删除前回读断言（FR-1.4）**；写后自动自检、可回滚（回滚=删看板 sheet）、运行日志留痕 |
| NFR-4 | 宿主范围 | 仅 Excel 宿主（D11）；WPS 下工具不出现，问及时告知原因与替代方案 |
| NFR-5 | 数据安全 | 生成过程不修改/不删除用户源数据表；辅助区放隐藏 sheet |
| NFR-6 | 可验证性 | 每次生成产出 verify 结果（图表/引用/联动对账），fail-closed；**渲染前增加 L1 spec 静态校验（字段白名单 + 类别数上限，对齐设计文档 §4.1）** |
