# 设计-公式构造与验证闭环（FormulaBuilder 三工具 + 模板库 + 批改器）

> 版本：v1.0（2026-09-18，用户点名范围后按倾向拍板冻结）
> 状态：**已实现**（本批次随 3.8.1.86 发版）

## 1. 背景与决策来源

用户在「强化写公式能力」调研后点名范围：**P1 三工具（build_formula / eval_formula / diagnose_formula）+ 公式模板库 + rewrite_formulas 批改器**。XLL UDF（需求稿 v0.4）不在本批。

**已拍板口径（按倾向，实现时冻结）**：
- 构造/诊断逻辑全部下沉 **Core 纯逻辑**（FormulaBuilder 静态类，确定性可单测，HypothesisTester 同款模式）；COM 触达只在服务层薄壳。
- **模板库并入 build_formula** 的 `template` 参数（不单独立工具）。
- 表头行对齐**内化进构造器**（`header_rows` 参数，默认 1）——根除「区域含表头文本」事故家族（qtyRef 等四处同类事故的体系性修复）。
- 同表裸地址、跨表统一 `'Sheet'!$A$1` 规范形态——内化「单限定引用被规范化到第一张 sheet」教训。
- eval_formula 用 `Application.Evaluate`（不写临时格，WPS 兼容 Evaluate 均支持）；Excel 错误值按 XlCVErr 映射（2000/2007/2015/2023/2029/2036/2042）。
- diagnose_formula 静态检查五类：HAS_ERROR_VALUE / DANGLING_SHEET_REF / EXTERNAL_REF / CIRCULAR_SELF / REFCODE_IN_TEXT；可选 eval 抽查（≤20 格）。
- rewrite_formulas 三操作：to_absolute / to_relative / wrap_iferror；区域上限 500 格（超出 RETURN TOO_MANY_CELLS）。

## 2. 工具面（4 个新注册，工具数 152→156）

| 工具 | 风险 | 说明 |
|---|---|---|
| `build_formula` | ReadOnly | 结构化构造：模板 + 源区域 + 列 + 条件 → 成品公式 + basis |
| `eval_formula` | ReadOnly | Application.Evaluate 试算，写前验证；返回值/错误映射 |
| `diagnose_formula` | ReadOnly | 区域公式静态体检五类根因 + 人话建议（对齐 diagnose_chart 模式） |
| `rewrite_formulas` | NormalWrite | 区域公式批改：相对/绝对转换、IFERROR 包装（≤500 格护栏） |

## 3. 模板库（build_formula 的 template 参数，18 个）

**基础聚合**：sum / count / max / min；**均值类**：average / average_ifs（强制 IFERROR 三件套）/ weighted_avg（SUMPRODUCT 加权，权重列必填）/ median / stdev；**条件类**：sumifs / countifs（criteria 智能形态：数字直传/运算符加引号/单元格引用直传（含跨表）/文本加引号）；**逐行类（混合引用 $X2，插入目标首格后向下填充联动）**：rank（RANK.EQ，RankOrder 0=降序默认）/ cumulative_sum（首端绝对+尾端相对）/ percent_of_total（行值/全列总和）；**双区域类（SecondSourceAddress+SecondValueColumn，行数一致性 fail-closed）**：growth_rate（(本期-上期)/上期）/ diff（差额）/ ratio（达成率/占比）；**去重**：distinct_count（SUMPRODUCT(1/COUNTIF)）。全部 IFERROR 兜底口径按模板语义预置。

## 4. 验证口径
