JYYJ助手 · 功能区命令组调研报告

调研微软 Copilot / WPS AI / Google Gemini / 国际 Excel AI 工具的功能区设计，结合本加载项现有 AI 工具层，给出下一批值得做的命令组与布局预览。

一、现状盘点

功能区现状：仅 1 个 Tab「JYYJ助手」，3 个命令——打开面板 / 聚光灯 / 指针。

底层 AI 工具层（已具备，但只能通过侧栏对话调用）：

已有工具
  • clean_excel_data 数据清洗（修日期/补空/删空行/分列）
  • create_excel_pivot_summary 一键透视
  • create_excel_chart 生成图表（含跨表）
  • filter_excel_data 筛选 / 排序
  • fill_blanks 智能填充「待补」
  • run_vba_snippet / run_python_excel 执行
已有能力
  • 公式逐层中文解释（选区 >20 公式时只解释活动格）
  • 四类自检 verify（写回/清洗/透视/标注）闭环
  • 标注 / 标记工具、工作表增删改名
  • 多模型侧栏对话（DeepSeek/Kimi/元宝/豆包/自定义）

结论：能力在，入口缺——最值得做的命令组，是把高频工具做成「选中区域 → 一键调用」的 Ribbon 按钮，并补齐业界公认的缺口（写公式、洞察、智能查找、翻译）。

二、调研发现（四路交叉验证）

微软 Copilot in Excel

核心能力：自然语言写公式 / 解释公式（2026 年更进一步推出原生 =COPILOT() 函数，可在单元格内直接用自然语言指示 AI 完成数据获取、整理、分析）[$TRAE_REF](https://juejin.cn/post/7547966981779341363)；智能数据清洗（一键去重、统一格式、修复脏数据、清理空白行）；公式自动生成与数据分析（自动生成文字结论、标注最值/环比/波动原因）[$TRAE_REF](https://m.sohu.com/a/1039597414_122744794/)。入口为 Home 选项卡按钮，无独立 Tab。

WPS AI 与国内大厂

WPS AI 以「AI 功能区」承载：生成公式（描述需求如"按区域汇总销售额"→ 自动写 SUMIF 等公式）、数据分析（对选中数据描述分析）、一键数据洞察自动生成分析报告 [$TRAE_REF](https://www.wps.cn/article/wps-ai-biaoge-zhushou.html)[$TRAE_REF](https://bbs.wps.cn/topic/83379)。国内插件共性：公式生成/解读排第一，其次是数据清洗/转换、数据分析、图表、翻译；另有金额大写、身份证提取等国内刚需。

Google Sheets Gemini

提供 =AI() 单元格函数（SpreadsheetBench 自动化操作得分 70.48%，"接近人类专家水平"），可靠完成分类 / 汇总 / 提取 / 情感分析；Fill with Gemini 拖拽式智能填充（含联网查填）[$TRAE_REF](https://www.vslzai.com/intelligence/google-sheets-ai-function-tutorial)[$TRAE_REF](https://www.ud.hk/zh-Hans/blogs/insight/article/2026-07-10-fill-with-gemini-sheets)；并可一句话建透视/图表、构建可视化表格 [$TRAE_REF](https://blog.google/products-and-platforms/products/workspace/gemini-workspace-updates-march-2026/)。

国际 Excel AI 工具（Ajelix / Formula Bot）

Ajelix：公式生成器 + 公式解释器（自然语言写公式、逆向把既有公式翻译成大白话）、公式翻译器（本地化版本间转换）、仪表板生成 [$TRAE_REF](https://aitoolsatlas.ai/tools/ajelix)[$TRAE_REF](https://ajelix.com/)。Formula Bot：公式生成与解释、数据变换（清洗/合并/重塑 + 情感分析/关键词提取/文本翻译）[$TRAE_REF](https://www.aiproverdict.com/compare/formula-bot-vs-ajelix)[$TRAE_REF](https://www.formulabot.com/excel-ai?via=free)。

四路收敛结论：业界一致把「写公式 / 数据清洗 / 一键洞察 / 智能填充与查找 / 文本翻译」列为最值得做的前五命令组；其中「写公式 + 解释公式」是各产品不约而同的旗舰能力。

五、落地建议

  1. 第一批（Tier1，全部复用现有工具，改动最小）：AI 公式（解释/写/检查）+ 数据清洗组 + 智能填充组 + AI 分析组。只需给每个按钮接「选中区域 → 调用既有工具 → verify 自检」通道，收益最高。
  2. 第二批（Tier2）：智能填充组补齐「智能查找 / 智能分类」新工具；文本翻译组做「整表翻译写回」和国内刚需（金额大写/身份证）。
  3. 分组位置：延续现有「JYYJ助手」Tab（insertAfterMso=TabHome），新增组按「写→洗→填→析→译→执行→视图」流程排列，与业界按任务类型分组的范式一致。
  4. 与自检体系打通：一键命令天然落入「主步骤 + verify 自检」闭环，继续满足清单约束兜底（verify 工具未配置 Tool 必须 fail-closed 阻断）。
