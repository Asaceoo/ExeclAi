1. 安装与卸载

1.1 安装版（推荐）

  1. 下载 JYYJ-3.9.2.0-Setup-wps.exe。
  2. 双击安装。安装器会：
  • 检测本机 Excel 与 WPS 的位数；
  • 按位数注册 32/64 位 COM 类（RegistryView 显式写入，不依赖安装器进程位数）；
  • 写入 Excel Addins 键与 WPS Addins/AddinsWL 白名单；
  • 设置 LoadBehavior=3（随 Excel 自动加载）。
  1. 完全退出 Excel 与 WPS（包括后台残留进程），再重新打开。
  2. 顶部出现 JYYJ助手 选项卡即安装成功。

1.2 便携 zip

下载 JYYJ-3.9.2.0-wps-x64.zip（或 x86），解压后同目录运行 register-x64.ps1（或 register-x86.ps1）。无需管理员权限。

1.3 程序目录包（高级）

下载 JYYJ-3.9.2.0-wps-portable-single-x64.zip，解压后是纯程序目录（加载项 DLL + 依赖 + WebView2 运行时，多个文件）。

这不是"单个 exe 双击即用"：本产品是 COM 加载项，可执行入口由 WPS/Excel 宿主提供，且依赖 WebView2 原生运行时。此包供外壳程序与需要自定义安装位置的高级用户使用，普通用户请走 1.1 安装版。

1.4 卸载

  • 安装版：设置 → 应用 → JYYJ助手 → 卸载；或用安装目录 unregister-all.ps1。
  • 便携版：运行同目录 unregister-all.ps1。
  • 卸载会清理 32/64 两个注册表视图的 COM 类、Excel/WPS 加载项键；不会删除你的 Excel 文件。
  • 用户数据（记忆、日志、技能）位于 %APPDATA%\ExcelAiAssistant 与 %LOCALAPPDATA%\XaiAssistant，如需彻底清除请手动删除。

1.5 面板/选项卡不显示

按顺序尝试：

# ① 仅诊断（只读，不改注册表）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\installer\diagnose.ps1

# ② 自动修复（改 HKCU 的 LoadBehavior/CLSID，无需管理员）
powershell -NoProfile -ExecutionPolicy Bypass -File tools\installer\repair-addin.ps1

修复后完全退出 Excel 再打开。若仍不见，检查 Excel → 文件 → 选项 → 加载项 → 管理「COM 加载项」→ 转到，确认「JYYJ助手」已勾选。

3. 5 分钟上手

  1. 配模型：设置 → 模型方案 → 填 Base URL / API Key / 模型名 → 点「测试」。
  2. 选数据：在表里选中区域（不选则按已用区域推断）。
  3. 说需求：「按月份汇总销售额，画柱状图放在右侧」。
  4. 看结果：回复列出工具、受影响区域、自检结论；每条写入可单独回滚。

提示：需求里写清目标位置、格式、口径，成功率更高；模糊时助手会先追问。

5. 聊天页

5.1 发送需求

  • 直接输入中文需求。
  • @ 可引用单元格/区域。
  • /技能名 强制调用某个技能。
  • 停止按钮可中断当前回合。

5.2 结果解读

一条 AI 回复通常包含：

  1. 做了什么（工具名 + 参数摘要）；
  2. 受影响区域（如 Sheet1!A1:B10）；
  3. 自检结论（verdict=ok 或具体差异）；
  4. 回滚入口（每个写入操作有 operation_id）。

5.3 上下文控制

  • 「压缩上下文」把长对话摘要化，节省 token。
  • 「单轮工具调用上限」可在设置页调大（复杂任务建议 20–50）。

5.4 写入模式

设置页「写入模式」：

模式行为
auto以 = 开头按公式，其余按值
value一律按文本/值写入（防公式注入，推荐）
formula一律按公式写入

7. VBA 页

  • 模板库：内置常用宏，可保存自定义模板。
  • 生成：描述需求生成 VBA，执行前展示代码。
  • 校验：静态检查（不执行）。
  • 执行：run_vba_snippet 属代码执行类，始终保留确认门。

安全提示：只运行你理解的代码；不要粘贴来源不明的宏。

8. Python 页

  • 两种模式：计算模式（用 Python 算，结果写回表格）/ Excel 模式（直接操作工作簿）。

  • 包管理：查看已装包、安装缺失包（install_python_packages 需确认）。
  • 环境自检：python_setup_guide 检查 Python 是否与 Excel 位数一致。

10. 流程页

  • 内置模板：月度经营分析、清洗体检、KPI 看板、公式审计、异常排查、结构盘点等。
  • 自定义流程：把多个工具串成步骤，每步可带 verify 自检。

11. 连接页（MCP / CLI）

11.1 开关

开关关闭后的行为
MCPExcelAiMcpServer.exe 启动即拒绝（exit 6），不创建 Excel 实例
CLIExcelAiCli 的 Excel 类命令拒绝执行（version/help/workflows 仍可用）
  • 开关真值：%LOCALAPPDATA%\XaiAssistant\connectors.json（面板与命令行读同一份）。
  • 只阻止新进程启动；已连接的客户端需重启对应进程才会断开。

11.2 测试连接

点「🔍 测试连接（真实握手）」：

  • CLI：运行 --version，校验退出码 0 与 JSON ok=true；
  • MCP：启动 --probe（不预热 Excel）走一次 initialize，校验 protocolVersion。

结果显示四种状态：✅ 成功 / ⏸ 已关闭（未测试） / ⚠ 未安装 / ❌ 失败。

11.3 客户端配置

面板下方提供 Claude Desktop 配置片段：

{
  "mcpServers": {
    "jyyj-excel": {
      "command": "C:\\Users\\<你>\\AppData\\Local\\XaiAssistant\\app\\x64\\ExcelAiMcpServer.exe"
    }
  }
}
  • 默认只读；勾选「包含写权限」才会加 --allow-write。
  • 粘贴位置：%APPDATA%\Claude\claude_desktop_config.json 的 mcpServers 下。
  • 未安装 MCP 程序时按钮置灰，可改用 npx jyyj-mcp config。

11.4 自主模式

  • 默认开启：结构/数据类危险操作直接执行（有审计、可回滚）。
  • 仍保留确认门：run_vba_snippet、run_python_*、run_cli_command、run_exe_command、install_python_packages、open_excel_external_book、replace_external_links。
  • 关闭自主模式：启动参数 --require-confirmation，或环境变量 JYYJ_AI_AUTONOMOUS=0。

15. 故障排查

现象处理
看不到「JYYJ助手」选项卡跑 diagnose.ps1 → repair-addin.ps1 → 完全退出 Excel 重开
侧边栏空白/白屏设置页看 WebView2 状态；重装 WebView2 运行时
模型「测试」失败核对 Base URL 是否含 /v1、Key 是否有效、是否需代理
提示「宏不可用 (0x800A9C68)」模块刚写入后的瞬态，会自动重试一次；持续出现检查宏设置
提示「当前没有打开的工作簿」先新建或打开一个工作簿
Excel 提示"正在编辑的文件被占用"关闭其他打开同一文件的 Excel 实例
写入超时/COM 忙稍后重试；关闭不用的 Excel 实例

16. 常见问题

Q：为什么 AI 说改了，表里没变化？

看回复的 verdict 与 error_code；也可以说"截图看看 A1:F20"。

Q：能处理多大数据量？

单次写入有格数上限，超限会明确报错；大表建议用透视/看板或分批。

Q：数据会不会上传？

只发送你提示中涉及的表格片段到你配置的 AI 端点；默认无遥测。

Q：能否离线？

可以，配置本地 Ollama 等 OpenAI 兼容端点即可。

Q：MCP 和加载项能同时用吗？

可以。它们各自独立；MCP 不操作你正在编辑的工作簿。

Q：关掉 CLI 开关后为什么 list 也不能用？

list 需要创建工具注册表（会启动一次隐藏 Excel），因此同样受开关控制；version/help/workflows 不受影响。
