# 设计-看板交互稿（聊天流内嵌卡片形态）

> 版本：v0.1（2026-09-10，界面形态经用户确认：chat-card）
> 上游：`docs/需求-原生数据看板.md`（FR）、`docs/设计-原生数据看板.md`（DashboardSpec 架构）
> 可视化稿：`看板交互稿.html`（随本次会话交付，六状态并排展示）

---

## 1. 形态决策记录

| 决策点 | 结论 | 理由 |
|---|---|---|
| 界面入口 | 侧边栏聊天流内嵌卡片 | 复用 AgentRunner 会话与确认门交互，改动面最小；spec 预览/确认/自检天然适合卡片形态 |
| 不做独立页签 | 二期再议 | 向导式整页 UI 工作量大，且脱离对话上下文后 AI 选型能力用不上 |
| 确认门交互 | 复用现有"允许执行"确认按钮语义 | render_dashboard 定为 StructuralChange（Q3 待终审），确认 UI 零新增 |

## 2. 状态机（六状态）

```
[空闲] ──用户说"做个销售看板"──► S1 选型卡
S1 ──用户选模板──► S2 spec 预览卡
S2 ──用户点"确认生成"──► S2.5 确认门（复用允许执行）──► S3 渲染进度卡
S3 ──渲染完成──► S4 自检中 ──verify 通过──► S5 结果卡
任意写后状态 ──verify 失败──► S6 错误卡 ──AI 修 spec──► 回 S2
S5 ──用户"重新生成/改参数"──► 回 S2
```

## 3. 卡片规格

### S1 模板选型卡
- 触发：AI 完成数据形态探测（列类型/时序/分类/悬殊值检测）；
- 内容：推荐模板名 + 一句话推荐理由（"检测到时间列+分类列，适合销售分析看板"）+ 2-3 个备选模板 chip；
- 操作：`[就用这个]` → S2；点备选 chip → 切换推荐；
- 边界：探测不出时间列时禁用趋势类模板并置灰说明。

### S2 spec 预览卡（核心卡片）
- 内容：按分组折叠展示 DashboardSpec 摘要——
  - 数据源：sheet 名 + 区域（点击可重新框选，复用现有选区注入格式 `'表'!$A$1:$F$6`）；
  - 联动：字段 chips + 模式（P1 显示"单元格联动"，native 探测通过后显示切换项）；
  - KPI：卡片名 + 聚合口径（求和/计数/均值/比率）；
  - 图表：类型 + 标题，版本敏感类型显示徽章（如"树状图 · 需 2021/365"）；
  - 主题：色板圆点；
- 操作：`[调整参数]`（展开内联编辑，仅开放安全子集：KPI 增删、图表换型、主题、联动字段；布局坐标不给用户改）→ `[确认生成]`；
- 副文案固定提示："将在新工作表生成看板，不会修改源数据"。

### S2.5 确认门
- 复用现有确认卡：操作摘要"新建工作表「销售看板」并写入看板元素（StructuralChange）"+ `[允许执行]`；
- 拒绝 → 回 S2，spec 保留。

### S3 渲染进度卡
- 内容：五步清单实时勾选——辅助汇总区 → KPI 卡片 → 图表 → 联动控件 → 布局美化；
- 操作：`[取消]`（对应 AC-5：中断即清理，无半成品残留）；
- 完成自动流转 S4，无需用户点击。

### S4/S5 自检与结果卡
- 自检项逐条展示（verify_dashboard 断言）：✓ 图表类型与数量 · ✓ 数据引用正确 · ✓ 次轴存在 · ✓ KPI 与 SUMIFS 对账一致 · ✓ 联动切换重算生效；
- 全过 → 结果卡：看板 sheet 跳转链接（复用现有 hyperlinked 定位）+ `[重新生成]` `[删除看板]`；
- 回滚承诺文案："可一键删除，源数据始终未被修改"。

### S6 错误卡（fail-closed）
- 内容：失败步骤 + 原始错误摘要（用户可读，不暴露 COM HRESULT 裸码）+ AI 修复建议（"建议将环形图改为堆积百分比，原因：分类数 >8"）；
- 操作：`[按建议重试]`（AI 修 spec → 回 S2 快速确认）｜`[仅重试]`｜`[放弃]`（确认清理）。

## 4. 工程改动清单（侧边栏侧）

| 改动 | 位置 | 量级 |
|---|---|---|
| 5 种新卡片组件 + 状态机 | 前端 index.html/JS | 主要工作量 |
| spec 预览/确认/进度/结果消息协议 | SidebarBridge 域（新增 dashboard 消息类型） | 中 |
| 选区重新框选注入 | 复用现有 sel_range 注入格式，零新增 | 无 |
| 确认门 | 复用现有允许执行卡，仅文案 | 无 |

前端契约变更走既有 busy 单层包装纪律（双层包装为已知缺陷模式）；卡片状态消息与执行链事件序列需真机验证前端 loading 不闪断。

## 5. 验收补充（挂接 PRD）

- AC-9（新增）：S1 选型卡在无时间列数据上禁用趋势模板并说明原因；
- AC-10（新增）：S3 取消后工作簿无新增 sheet（对齐 AC-5）；
- AC-11（新增）：S6 错误文案不含 COM 裸错误码，含可执行修复建议。
