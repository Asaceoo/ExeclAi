一、安装前准备

本安装器是一个同时适配 32 位与 64 位 Excel 的合并安装包
文件：JYYJ助手-2.18.6.0-Setup.exe。安装时会自动探测你电脑上 Excel 的位数，并注册到对应的系统位置，无需你手动区分版本。

务必提前确认
  • 已安装受支持的 Microsoft Excel（Excel 2016 / 2019 / 2021 / Microsoft 365 等桌面版）。
  • 安装前保存并关闭所有打开的 Excel 窗口，否则安装会提示你关闭后才能继续。
  • 系统为 Windows 7 SP1 及以上（Win10 / Win11 最佳）。

系统级依赖说明

加载项自带全部托管程序集与各架构的原生依赖（SQLite.Interop、WebView2Loader.dll），无需单独下载。
另有两项系统级依赖，安装程序会自动检测并友好提示（提示不阻断安装）：

依赖作用缺失时的提示
.NET Framework 4.x加载项运行所必需建议先安装 .NET Framework 4.8 再使用
WebView2 Runtime侧边栏界面渲染若缺失界面可能空白，需安装 Evergreen WebView2 Runtime

二、安装步骤

1
双击运行安装包
找到 JYYJ助手-2.18.6.0-Setup.exe，双击启动。若弹出 Windows 用户账户控制（UAC），点「是」允许。
2
等待关闭 Excel 检查
安装程序会检测 Excel 是否在运行。若正在运行，会弹出提示，请保存文件并关闭所有 Excel 后再点「重试」。
3
默认安装位置
程序默认安装到用户数据目录，无需修改权限：
%LocalAppData%\XaiAssistant（即 C:\Users\你的用户名\AppData\Local\XaiAssistant）
4
自动注册加载项
安装完成时会自动执行注册脚本（状态提示「正在注册 Excel 加载项…」），把加载项注册到当前 Excel 位数对应的系统位置。全程无额外窗口弹出。
5
安装完成
点「完成」结束安装。本安装器不创建桌面/开始菜单快捷方式，一切入口都在 Excel 内。
安装到同一台电脑的修复/重建
如需修复，直接再次运行同一安装包即可（覆盖更新，不会影响你的数据目录）。安装前同样需要先关闭 Excel。

三、安装后核对

  1. 启动 Excel，在功能区（Ribbon）顶部应出现「JYYJ助手」选项卡。
  2. 点击该选项卡（或其中的侧边栏按钮），Excel 右侧弹出侧边栏面板。
  3. 侧边栏左下角或顶部应显示连接状态为「就绪」，说明加载项与 Excel 通讯正常。
  4. 在侧边栏「设置」→「关于 / 版本」中核对版本号应为 2.18.6.0。
首次启动若看不到侧边栏
Excel 会自动加载已注册的加载项。若功能区没有出现「JYYJ助手」选项卡，请完全退出 Excel（含后台进程）后重新打开；仍无效则参见「常见问题」。

四、初次使用（配置模型）

JYYJ助手需要一个 OpenAI 兼容接口 的模型服务才能对话和操作表格。首次使用请先在侧边栏完成配置：

  1. 打开侧边栏，切到「设置」视图。
  2. 找到「模型方案（OpenAI 兼容）」卡片。
  3. 填写接口地址（Base URL）、API Key，选择或填写模型名称。
  4. 保存后回到「聊天」视图，即可开始提问，例如：把 A 列金额求和到 C1。
配置保存位置
模型配置保存在 %APPDATA%\ExcelAiAssistant\ 下的本地配置文件中，仅存于你本机。

五、升级到新版本

  1. 关闭所有 Excel 窗口。
  2. 双击运行新版安装包（版本号比已装的高）。
  3. 安装程序会覆盖应用文件并重新注册加载项；你的模型配置、记忆、自建技能等用户数据会原样保留。
  4. 完成后重新打开 Excel 即可使用新版本（可在「关于 / 版本」中确认）。

六、卸载

两种方式任选其一：

方式一：通过「应用和功能」卸载（推荐）

  1. 先关闭所有 Excel 窗口（否则清理注册项时可能受限）。
  2. Windows「设置」→「应用」→「已安装的应用」→ 搜索 JYYJ助手。
  3. 点击「卸载」并确认。卸载程序会自动清理 32/64 两个注册表视图下的全部注册项，再删除安装文件。

方式二：通过控制面板卸载

「控制面板」→「程序和功能」→ 找到 JYYJ助手 2.18.6.0（Excel 加载项） → 右键「卸载」。

卸载后保留
模型配置、长期记忆、自建技能等用户数据目录不会被删除，若需彻底清除请手动删除 %APPDATA%\ExcelAiAssistant\ 与 %LocalAppData%\XaiAssistant\。

七、常见问题（FAQ）

1. 我的 Excel 是 64 位还是 32 位？需要自己选安装包吗？

不需要。这个合并安装包会自动识别你的 Excel 位数，32 位和 64 位 Excel 都能用，请放心使用同一个安装文件。

2. 安装时提示「检测到 Excel 正在运行」？

安装会更新被 Excel 占用的加载项文件，必须先关闭 Excel。保存文件后点「重试」。若已关闭仍有提示，请在任务管理器结束残留的 excel.exe 进程。

3. 安装后打开 Excel，功能区没有「JYYJ助手」选项卡？

  • 确认安装包与启动的 Excel 位数匹配（本包自适配，一般不会出现）；
  • 完全退出 Excel（右下角托盘及任务管理器都无 excel.exe）再重新打开；
  • 检查是否被 Excel 的「加载项」安全设置禁用：文件 → 选项 → 加载项 → 管理处选择「COM 加载项」→ 转到，勾选「ExcelAiAssistant.AddIn / JYYJ助手」。

4. 侧边栏打开是空白？

通常是 WebView2 Runtime 缺失。请安装「Evergreen WebView2 Runtime」后重启 Excel；Win10/11 通常已自带。

5. 升级后会丢失我的配置吗？

不会。升级只覆盖应用目录，你的模型配置、记忆、技能均保留。安装时同样请先关闭 Excel。

6. 如何彻底卸载并清理所有痕迹？

按「六、卸载」操作后，再手动删除两个数据目录（见卸载章节的提示），即可完全清除。

7. 本安装器是否会修改系统其它地方？

仅写入当前用户注册表下的 .NET COM 加载项与 Excel Addins 键（并支持 32/64 双视图清理），隶属于你的用户账户，无需管理员权限。
