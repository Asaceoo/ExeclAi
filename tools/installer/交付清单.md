# 安装包交付清单（发版前逐项勾验，任一不过不许发）

> 用法：每次编译出新安装包后，按本清单逐项核验。清单即"最低验收标准"。

## 1. 源文件完整性（编译前置）

- [ ] `tools/installer/安装说明.txt` 存在，UTF-8 **带 BOM**（Win7 记事本不乱码）
- [ ] `tools/installer/diagnose.ps1` 存在，UTF-8 **带 BOM**（PowerShell 5.1 中文必需）
- [ ] `tools/installer/一键诊断.cmd` 存在，**GBK/ANSI 编码**（cmd 控制台中文）
- [ ] `diagnose.ps1` 语法解析通过（Parser::ParseFile 零错误）
- [ ] `diagnose.ps1` 的 ProgID/CLSID 清单与 `register-auto.ps1` L75-77 **三对一致**
- [ ] 两个 iss 的 `[Files]` 均含上述三个用户支持文件
- [ ] 两个 iss 的 `[Icons]` 均含"安装说明"与"一键诊断"两个开始菜单入口

## 2. 编译产物

- [ ] 轻量版 `dist/installer/JYYJ助手-<版本>-Setup.exe` 存在且体积在 4~6MB 区间（双架构 app 原始约 15MB，lzma2 压缩后实测 4.65MB；**显著偏离即 PkgSrc 路径错误**）
- [ ] 离线完整版 `JYYJ助手-<版本>-Setup-离线完整版.exe` 存在且体积在 290~320MB（+约 297MB 依赖捆绑；实测 301/311MB）
- [ ] iss 内 PkgSrc64/PkgSrc86 路径指向**当前版本**的 dist 目录（无旧版本残留）
- [ ] 两个 iss 均含 `DisableDirPage=yes` 与 PrepareToInstall 的 Excel 运行检测（IsExcelRunning + 重试循环）
- [ ] `register-auto.ps1` 与 `unregister-all.ps1` 均含无花括号垃圾键清理段（历史版本升级/卸载自愈）

## 3. 真机试装（静默 `/SILENT /NORESTART /LOG=...`）

- [ ] 退出码 = 0
- [ ] 安装日志无 Error 行
- [ ] `%LocalAppData%\XaiAssistant` 下新支持文件全部落盘：
  `安装说明.txt` / `diagnose.ps1` / `一键诊断.cmd`
- [ ] 开始菜单组出现"JYYJ助手 安装说明"与"JYYJ助手 一键诊断"
- [ ] 三个 Addins 键 LoadBehavior=3（HKEY_CURRENT_USER\SOFTWARE\Microsoft\Office\Excel\Addins\ExcelAiAssistant.*）
- [ ] 从**安装目录**（非源码目录）真跑 `diagnose.ps1`：
  - 报告生成到桌面且可打开
  - §5"安装文件完整性"不再报"diagnose.ps1/安装说明.txt 缺失"
  - §4 CodeBase 指向 `%LocalAppData%\XaiAssistant\app\...`（非开发目录）
  - §7 若有问题，每条均有可执行建议

## 4. 诊断工具自证（每次改 diagnose.ps1 后必跑）

- [ ] 本机真跑一次，报告生成、notepad 自动打开
- [ ] 人工抽查报告 §1-§7 各节无"采集失败"以外的异常字样
- [ ] Excel COM 探测后无残留 EXCEL.EXE 进程（任务管理器确认）

## 5. 版本纪律（发版红线）

- [ ] 版本号单一来源：`Addin.csproj <Version>` → package-xai.ps1 自动同步 README/iss（含 -Setup-wps.iss）/手册版本戳（JYYJ助手技术手册/用户手册-<版本>.md/.html，动态解析兼容旧英文名）
- [ ] 全部安装器文件名均含新版本号（轻量版 / 离线完整版 / WPS 版 `-Setup-wps.exe`）
- [ ] `verify-versionbump.ps1` 47 断言全过（含 WPS iss 5 项：生成/AppVersion/PkgSrc/无残留/旧文件不动）

## 历史教训关联

- WebView2 检测必须查 **32 位视图**（WOW6432Node）+ HKCU，参见踩坑手册 §6.7
- `@echo off` 类 cmd 内容用 GBK；`Get-Content -Tail` 等新参数避免使用（兼容 Win7 PS 2.0）
- 同一文件多处修改**禁止并行编辑**（竞态丢补丁，以逐项 contains 断言核验）
- Excel 运行检测**禁用 `tasklist /FI` 过滤器**（实测可静默失灵漏报），用全量输出+按名搜索（§6.8 坑4）
- 验证前确认**被测对象是最新产物**（安装目录 vs 源码目录脚本版本，§6.8 教训）
