  JYYJ助手（Excel / WPS 表格 AI 助手）安装说明 · 小白版
  适用版本：3.9.1.3（安装包文件名里就能看到版本号）
═══════════════════════════════════════════════════════

◎ 这是什么？

  一个装在 Excel 或 WPS 表格里的 AI 助手：用大白话告诉它你想做什么，
  它帮你读表、填表、洗数据、做图表、写公式、写报告。

═══════════════════════════════════════════════════════
【安装只需要两步】
═══════════════════════════════════════════════════════

  第零步（建议做）：把打开中的 Excel 和 WPS 都关掉
          · 不关也能装——安装器会问你"要不要自动关闭"，点【是】即可
            （注意：没保存的表格内容会丢失，先保存再点是）
          · 如果弹出 UAC 窗口（"是否允许此应用对设备进行更改"），点【是】
            ——安装器需要这个权限才能关掉以管理员运行的 Excel

  第一步：双击安装包（文件名带 Setup 的 .exe 文件）
          · 一路点【下一步】→【安装】→【完成】即可
          · 什么都不用配置，环境依赖会自动处理
            （离线完整版会自动安装缺失的系统组件；轻量版缺组件时会提示）

  第二步：打开 Excel 或 WPS 表格
          · 顶部菜单栏会出现一个【JYYJ助手】选项卡
          · 点开它就能使用 AI 助手了

═══════════════════════════════════════════════════════
【装不上 / 提示"自动关闭失败"？】
═══════════════════════════════════════════════════════

  安装器已经帮你强关过 Excel/WPS（含提权限强杀），仍提示有进程活着：

  1. UAC 窗口出现过但没点"是"？→ 重新选【是】，UAC 弹出时点"是"
  2. 杀毒软件拦了？→ 手动关闭 Excel 和 WPS（含屏幕右下角托盘图标），再试
  3. 怎么都不行？→ 重启电脑后再装（极少数被其他程序拉起的进程只有
     重启才能清掉）

  想看安装器到底关了哪些进程？
  打开这个文件：%LocalAppData%\XaiAssistant\logs\hostkill.log

═══════════════════════════════════════════════════════
【装完之后找不到 JYYJ助手 选项卡？】
═══════════════════════════════════════════════════════

  先分清你开的是哪个软件：

  ▸ Excel 用户：
    1. 点【文件】→【选项】→【加载项】→ 最下方"管理"选【COM 加载项】
       → 点【转到】→ 勾选 JYYJ助手 → 确定
    2. 还不行？用下面的"一键诊断"

  ▸ WPS 表格用户：
    1. 确认 WPS 是 2019 或更高版本（旧版 WPS 不支持）
    2. 完全退出 WPS（含托盘图标）再重新打开试一次
    3. 还不行？用下面的"一键诊断"

═══════════════════════════════════════════════════════
【遇到问题 / 报错怎么办：一键诊断】
═══════════════════════════════════════════════════════

  · 点【开始菜单】→【JYYJ助手】→【一键诊断】
    （或在安装目录 XaiAssistant 文件夹里双击"一键诊断.cmd"）
  · 它会自动检查你的电脑环境（Excel 和 WPS 都查），并在桌面生成一份
    诊断报告（文件名形如：JYYJ诊断报告-日期.txt）
  · 同时会检查随包的用户手册（用户手册.html）是否存在，缺了会提醒
  · 把这份报告完整发给我们，比任何描述都快

═══════════════════════════════════════════════════════
【常见问题】
═══════════════════════════════════════════════════════

  Q1：提示缺少 .NET Framework 4.8 或 WebView2？
      → 下载"离线完整版"安装包，它会自动帮你装好这两个组件。

  Q2：安装时杀毒软件报警 / 拦截？
      → 这是加载项需要写入注册表触发的正常提醒，选择"允许"即可。

  Q3：Excel 一打开就弹"运行错误"对话框？
      → 运行"一键诊断"并把报告发给我们。

  Q4：WPS 里有些 AI 功能（比如执行 VBA 代码）说不可用？
      → WPS 个人版出厂不带 VBA（版权原因），需一次性补装 VBA 模块并开
        两个安全开关。跟着随包《用户手册.html》里"常见问题 7"的三步
        操作做即可；不做也不影响其他功能。

  Q5：想卸载？
      → Windows【设置】→【应用】→ 找到"JYYJ助手"→ 卸载。
        卸载会同时清理所有注册项，装回旧版本直接双击旧安装包即可。

═══════════════════════════════════════════════════════
【系统要求】
═══════════════════════════════════════════════════════

  · Windows 10 / 11
  · Microsoft Excel 2013 / 2016 / 2019 / 2021 / Microsoft 365
    （32 位和 64 位都支持）
  · WPS 表格 2019 及以上（32 位和 64 位都支持；个人版 VBA 见 Q4）
  · 随包《用户手册.html》有更完整的使用说明和常见问题
